# Plans

The only part of the wiki allowed to differ from the code. One file per feature, with `status` in
frontmatter (`draft → approved → in-progress → implemented`). Workflow in `AGENTS.md`.

A plan page contains: goal · context (wikilinks) · design · file-by-file changes · interfaces ·
milestones · verification steps · open questions / risks.

When a plan is implemented, its durable content moves into `codebase/`, the plan file is deleted, and
`changelog.md` + `log.md` get entries.
