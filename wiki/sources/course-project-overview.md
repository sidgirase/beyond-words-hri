# CS 7633 Fall 2026 — Project overview (course handout)

## Requirements
- Groups up to 4; scope scales with group size. Categories: robot design, algorithmic HRI, user
  interaction, survey. This project is user-interaction + some algorithmic work.
- Perception-only work isn't HRI enough; "grounding human instructions" is explicitly called a great topic.
- Proposal: 2–3 pages, ≥4 papers (≥1 pre-2021), ≥7 bolded HRI Research Methods Glossary terms,
  self-proposed 150-point final rubric.

## Deadlines and grading
See [[timeline]]. Deliverables [1]–[5] are graded 50 pts each on a Mature/Evolving/Needs improvement
scale ("Minimal evidence of deliverables beyond preparation" → ≤40). Final report: 150 pts on the
team's own rubric. Total 400.

## Suggested simulators
Habitat, Isaac Sim, CARLA, SEAN 2.0, AI2-THOR. MuJoCo/`stretch_mujoco` is not on the list — it's the
team's own choice ([[stretch-3-robot]]).
